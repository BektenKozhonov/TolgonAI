# TolgonAI

**TolgonAI** — это проект голосового помощника, изначально задуманный для помощи пожилым людям. На текущем этапе разработки TolgonAI функционирует как текстовый ассистент, который отвечает на вопросы и предоставляет поддержку в текстовом формате.

## Особенности

- Интуитивно понятное взаимодействие через текст.
- Разработан с учетом потребностей пожилых людей.
- Основа для будущего голосового помощника.
