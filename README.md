# TolgonAI

**TolgonAI** — это проект текстового помощника, изначально разработанный для пожилых людей. Изначально планировалось создание голосового ассистента, однако на текущем этапе TolgonAI предоставляет поддержку в текстовом формате. 

Проект использует современные технологии для распознавания и обработки речи, а также реализован как Telegram-бот для удобства пользователей.

## Особенности

- **Распознавание голоса:** Использует [Whisper AI от OpenAI](https://platform.openai.com/docs/guides/whisper) для преобразования речи в текст.
- **Обработка запросов:** Ответы формируются с использованием модели `gemini-1.5-flash-002`, предоставленной Google gemini.
- **Telegram-бот:** Реализован на базе библиотеки [Telebot](https://pypi.org/project/pyTelegramBotAPI/), которая обеспечивает простую и понятную интеграцию с Telegram.
- Идеально подходит для пользователей, которые предпочитают взаимодействовать через текст.
- Интуитивно понятное взаимодействие через текст.
- Разработан с учетом потребностей пожилых людей.
- Основа для будущего голосового помощника.
